# 🎯 Number Guessing Game (Python)

## 📌 Project Overview

The **Number Guessing Game** is a simple Python console application where the player tries to guess a randomly generated number. The game offers three difficulty levels and provides hints after each guess until the correct number is found.

This project demonstrates the use of Python fundamentals such as loops, conditional statements, exception handling, functions, dictionaries, and the `random` module.

---

## ✨ Features

* 🎮 Three difficulty levels:

  * Easy (1–50)
  * Medium (1–100)
  * Hard (1–500)
* 🔢 Random number generation
* 📈 Hints for guesses that are too high or too low
* 📝 Tracks the total number of attempts
* ⚠️ Input validation using `try-except`
* 🔁 Option to play multiple rounds
* 💻 Simple and user-friendly console interface

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone the repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python guessing_game.py
```

---

## 🎮 How to Play

1. Start the game.
2. Select a difficulty level.
3. Enter your guesses within the specified range.
4. Read the hints:

   * 📉 Too Low
   * 📈 Too High
5. Continue guessing until you find the correct number.
6. Choose whether to play another round.
